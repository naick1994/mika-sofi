# Mika & Sofi — Website

Single-page site for pro kitesurfers Mika & Sofi. Static HTML/CSS/JS, no build step.

## Struttura
- `index.html` — tutta la pagina (HTML, CSS e JS inline)
- `assets/img/` — foto ottimizzate
- `assets/logo/` — loghi SVG

## Lingue
EN / IT / PT-BR, switch in alto a destra. La lingua scelta viene ricordata.

## Form di contatto
Il form usa Formspree. Sostituisci `YOUR_FORM_ID` in `index.html`:
1. Crea un form gratis su https://formspree.io con la tua email
2. Copia l'ID e incollalo al posto di `YOUR_FORM_ID` nell'action del form

## Pubblicare su GitHub Pages
1. Crea un repo, carica tutti i file (mantieni la cartella `assets`)
2. Settings > Pages > Source: branch `main`, cartella `/root`
3. Online in 1-2 minuti

## Da completare
- Sostituire le foto di Sofi (ora ci sono solo quelle di Mika)
- Inserire il Formspree ID
- Verificare/aggiornare i numeri social
